# DemoCrazyLand

(*#indiaScam #voteChori*)

[![Deploy to Github-Pages](https://github.com/bRuttaZz/democrazyland/actions/workflows/static-site.yml/badge.svg)](https://github.com/bRuttaZz/democrazyland/actions/workflows/static-site.yml)

Live Demo: [democrazyland](http://brutt.site/democrazyland)

Years before some thieves have entered the world's most Sacred DemoCrazy-Land! And they're causing some big troubles. Let's see if you can help resolve the serious-flashy-latest issue.

**There is no AI (LLM) generated content here**: This repo is more of a protest than a skill showoff, hence all of the content, both art and code, is purely hand-drawn/written, as the **currently non-sustainable, under-restricted, monetary corporate systems like LLMs, trained on top of millions of pirated works, seemed too far off from our policies**. Hence, they were kept out of this protest.
